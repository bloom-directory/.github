[Bloom](https://bloom.directory) is building file-native infrastructure for trusted human-agent software collaboration. Based on a primitive called "Petals", these are "agent-safe software components".

The core interface is a `/bloom` namespace: agents read state like files, stage actions by writing to files, and leave humans with explicit plans to review before anything sensitive is signed or deployed. Under the hood, Bloom combines verifiable execution, content-addressed modules and human-defined invariants.

* [Bloom](https://github.com/bloom-directory/bloom): walletFS: an agentic Ethereum wallet exposed as a virtual filesystem, with chain views, wallet action staging, and reviewable transaction plans.
* [Bloom Docs](https://github.com/bloom-directory/docs): user-facing documentation, quickstarts, and the canonical setup path for agents using Bloom.
